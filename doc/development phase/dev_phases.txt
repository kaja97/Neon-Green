AgriFarm AI — Development Phases (v1.0)
=========================================
Timeline: ~12 weeks (no AI chat in v1.0)
See doc/09_IMPLEMENTATION_ROADMAP.md and doc/16_SERVICE_GATING.md

Phase 0 — Environment + Seed Data (Week 1)
  Docker Compose: PostgreSQL 16 + Redis 7
  Backend: FastAPI skeleton, Alembic migration, requirements.txt or Poetry
  Frontend: Next.js 14, Tailwind, lib/api.ts
  Seed: 5 crops, stages, nutrients, diseases, solutions
  Deliverable: docker-compose up → DB ready → /docs shows API

Phase 1 — Auth + Farmer Profile (Week 2)
  Register/login/refresh, JWT, farmer profile CRUD
  Location on register + Leaflet map picker
  account_features seeded on registration
  Deliverable: Farmer registers, adds GPS location

Phase 2 — Project CRUD + Dashboard Shell (Weeks 3–4)
  Project create wizard, dashboard aggregation
  project_services created per project from account access
  FarmingCircle, service block placeholders (hidden if not enabled)
  Deliverable: "Tomato 1 acre" project with Farming Circle

Phase 3 — Activity Planner — CORE (Weeks 5–6)
  generate_season_plan on project create (sync or Celery)
  Today's tasks, mark done/skip, activity timeline
  activity_plan always enabled — no gating needed
  Deliverable: ~77 activities generated, farmer marks tasks done

Phase 4 — Weather (Week 7) [gated: weather]
  OpenWeatherMap, Redis/DB cache, adjustment rules
  Celery Beat: refresh cache, adjust plan, alerts
  require_project_service("weather") on API
  Deliverable: Activities auto-adjust; alerts shown

Phase 5 — Soil + Disease (Weeks 8–9) [gated: soil, disease_watch]
  Nutrient gap calculator, soil test form
  Disease keyword search (FTS), issue reporting
  NO AI fallback in v1.0 — return "no match" message
  Deliverable: Soil recs + disease match with solutions

Phase 6 — Market + Notifications (Week 10) [gated: market_price]
  Market prices, trends, revenue estimate
  Web Push VAPID, notification center
  Deliverable: Price display + daily task push

Phase 7 — Polish, Testing, Deploy (Weeks 11–12)
  pytest unit/integration, PWA offline, Lighthouse
  Docker production build, VPS deploy, CI/CD
  Deliverable: v1.0 live — planner + optional services
