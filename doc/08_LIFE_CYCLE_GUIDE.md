# AgriFarm AI — Life Cycle Plan & Daily Guidance Engine

## Overview

The **Life Cycle Plan** is the core concept of AgriFarm AI. When a farmer creates a project, the system automatically generates a complete activity plan that covers the entire growing season (typically 90-120 days).

This plan is:
- **Deterministic** — generated by Python algorithms, not AI (zero cost)
- **Stage-based** — driven by the crop's biological growth stages
- **Weather-adjusted** — modified daily by weather forecast data
- **Farming-method-aware** — different recommendations for organic vs conventional

```

     ○                ✓
        ╲           ╱
            ★ ← YOU ARE HERE
```

Each dot shows:

## 2. Plant Stages (The Foundation)

Every crop in the master catalogue has predefined growth stages stored in the `plant_stages` table. These are seeded by admin and form the backbone of the life cycle.

### Example: Tomato (90 days)

| Stage | Order | Days | Key Indicators | Critical Actions | Watch For |
|-------|-------|------|-----------------|-----------------|-----------|
| Germination | 1 | 0-7 | Seeds sprouting, first root visible | Keep soil moist, maintain 25-30°C | Damping off disease |
| Seedling | 2 | 8-21 | True leaves appear, stem thickening | Light fertilizer, harden off | Aphids, overwatering |
| Vegetative | 3 | 22-42 | Rapid leaf growth, branching | Heavy nitrogen, stake/cage plants | Leaf curl, whitefly |
| Flowering | 4 | 43-60 | Yellow flower clusters | Switch to potassium, reduce nitrogen | Blossom drop, blight |
| Fruiting | 5 | 61-80 | Green fruits forming and ripening | Maintain potassium, consistent water | Fruit rot, cracking |
| Harvest | 6 | 81-90 | Fruits red and firm | Pick regularly, check market prices | Over-ripening, pests |

## 3. Activity Plan Generation (Deterministic Algorithm)

When a project is created, the `generate_season_plan()` Celery task generates **all activities** for the entire season in one batch.

### What Gets Generated

| Activity Type | Source Table | Logic |
|--------------|-------------|-------|
| Watering | `plant_water_requirements` | Every N days per stage, volume scaled to farm area |
| Fertilizing | `plant_fertilizer_recommendations` | At stage transitions, filtered by farming method |
| Monitoring | `plant_stages.watch_for` | Weekly per stage, inspect for stage-specific threats |
| Pruning | Stage-specific rules | Vegetative stage: pruning tasks |
| Harvesting | Final stage | Daily harvest collection tasks |

### Generation Algorithm

```python
def generate_season_plan(project_id: str):
    project = get_project(project_id)
    plant = project.plant
    stages = get_plant_stages(plant.id)  # Ordered by stage_order
    area = float(project.area)
    method = project.farming_method.code  # "organic" or "inorganic"
    start = project.planting_date

    activities = []

    for stage in stages:
        stage_start = start + timedelta(days=stage.start_day)
        stage_end = start + timedelta(days=stage.end_day)
        stage_duration = stage.end_day - stage.start_day

        # ── WATERING ──────────────────────────────
        water = get_water_requirement(plant.id, stage.id)
        if water:
            interval = water.irrigation_frequency_days or 2
            for offset in range(0, stage_duration, interval):
                day = stage_start + timedelta(days=offset)
                volume = float(water.water_mm_per_day) * area * 4.047  # acres → liters
                activities.append(Activity(
                    project_id=project_id,
                    stage_id=stage.id,
                    type="watering",
                    title=f"Water plants — {round(volume)}L",
                    description=f"Apply via {project.land_detail.irrigation_type or 'manual'}",
                    date=day,
                    time=time(6, 0),  # 6 AM
                    priority=2
                ))

        # ── FERTILIZING ──────────────────────────
        ferts = get_fertilizer_recs(plant.id, stage.id)
        for f in ferts:
            # Filter by farming method
            if method == "organic" and not f.is_organic:
                continue
            if method == "inorganic" and f.is_organic:
                continue

            qty = float(f.quantity_per_acre) * area
            activities.append(Activity(
                project_id=project_id,
                stage_id=stage.id,
                type="fertilizing",
                title=f"Apply {f.fertilizer_type} — {round(qty, 1)} {f.unit}",
                description=f"Method: {f.application_method}. {f.timing_note or ''}",
                date=stage_start + timedelta(days=2),  # Early in stage
                time=time(7, 0),  # 7 AM
                priority=1  # Fertilizing is high priority
            ))

        # ── MONITORING ───────────────────────────
        for week in range(0, stage_duration, 7):
            activities.append(Activity(
                project_id=project_id,
                stage_id=stage.id,
                type="monitoring",
                title=f"Inspect: {stage.watch_for or 'general health'}",
                description=stage.key_indicators or "Check plant health visually",
                date=stage_start + timedelta(days=week + 3),  # Mid-week
                time=time(8, 0),
                priority=3
            ))

    # Bulk insert all activities (typically 50-100 activities)
    db.bulk_save_objects(activities)
    db.commit()
    return len(activities)
```

### Typical Output for 1 Acre Tomato (90 days)

| Activity Type | Count | Frequency |
|--------------|-------|-----------|
| Watering | ~45 | Every 2 days |
| Fertilizing | ~6 | Once per stage transition |
| Monitoring | ~12 | Weekly |
| Pruning | ~4 | During vegetative stage |
| Harvesting | ~10 | Daily during harvest stage |
| **Total** | **~77** | |

## 4. Daily Guidance Engine (Weather Adjustment)

Every morning at **5:00 AM**, a Celery Beat task runs:

### Step 1: Fetch Weather
```
For each active project location:
  → Fetch 5-day forecast from OpenWeatherMap (free tier)
  → Cache in Redis (3-hour TTL) and weather_cache table
```

### Step 2: Evaluate Today's Activities
```python
def adjust_today(project_id):
    weather = get_today_weather(project_id)
    activities = get_today_pending(project_id)

    for activity in activities:
        # ── WATERING RULES ──────────────────
        if activity.type == "watering":
            if weather.rain_mm > 5:
                activity.status = "skipped"
                activity.skipped_reason = f"Rain expected: {weather.rain_mm}mm"
                activity.is_weather_adjusted = True
            elif weather.rain_probability > 0.7:
                activity.status = "rescheduled"
                activity.scheduled_date += timedelta(days=1)
                activity.is_weather_adjusted = True

        # ── FERTILIZER RULES ─────────────────
        if activity.type == "fertilizing":
            if weather.rain_mm > 25:
                activity.status = "rescheduled"
                activity.skipped_reason = "Heavy rain — fertilizer would wash away"
                activity.scheduled_date += timedelta(days=2)
                activity.is_weather_adjusted = True

        # ── SPRAYING RULES ──────────────────
        if activity.type == "spraying":
            if weather.wind_speed > 20:
                activity.status = "rescheduled"
                activity.skipped_reason = "High wind — spray would drift"
                activity.scheduled_date += timedelta(days=1)
                activity.is_weather_adjusted = True

    db.commit()
```

### Step 3: Generate Alerts
```python
def check_alerts(project_id):
    weather = get_5day_forecast(project_id)
    stage = get_current_stage(project_id)

    # Flood risk
    if any(d.rain_mm > 50 for d in weather):
        create_alert(project_id, "flood_risk", "critical",
                     "Heavy rainfall expected. Protect drainage channels.")

    # Frost risk
    if any(d.temp_min < 10 for d in weather):
        create_alert(project_id, "frost_risk", "critical",
                     "Cold temperatures expected. Cover sensitive crops.")

    # Disease risk (high humidity during flowering/fruiting)
    if (stage.stage_name in ["Flowering", "Fruiting"]
            and any(d.humidity > 85 and d.temp_max > 25 for d in weather)):
        create_alert(project_id, "disease_risk_humidity", "warning",
                     "High humidity + warm temperature = ideal for fungal diseases. "
                     "Inspect daily. Apply preventive spray if needed.")

    # Drought risk
    if sum(d.rain_mm for d in weather) < 2 and stage.stage_name == "Vegetative":
        create_alert(project_id, "drought_risk", "warning",
                     "No rain expected for 5 days during critical growth. Increase irrigation.")
```

## 5. Stage Transitions

The system automatically detects stage transitions based on the current day:

```python
def get_current_stage(project_id):
    project = get_project(project_id)
    days = (date.today() - project.planting_date).days
    stages = get_plant_stages(project.plant_id)

    for stage in stages:
        if stage.start_day <= days <= stage.end_day:
            return {
                "stage": stage,
                "day_in_stage": days - stage.start_day,
                "stage_progress_pct": ((days - stage.start_day) / (stage.end_day - stage.start_day)) * 100,
                "total_progress_pct": (days / project.plant.growth_duration_days) * 100
            }

    return {"stage": stages[-1], "day_in_stage": 0, "total_progress_pct": 100}
```

When a stage transition is detected:
1. Mark previous stage activities as "completed" if still pending
2. Send notification: "Your crop has entered the [Flowering] stage!"
3. Update the Farming Circle UI

## 6. Activity Status Flow

```
┌──────────┐     Farmer taps     ┌──────────┐
│ pending  │ ──── "Done" ─────→ │  done    │
└──────────┘                     └──────────┘
      │
      │ Weather engine           ┌──────────┐
      ├──── auto-skips ───────→ │ skipped  │
      │                          └──────────┘
      │
      │ Weather engine           ┌──────────────┐
      └──── reschedules ──────→ │ rescheduled  │ → creates new pending activity
                                 └──────────────┘
```

### Done/Skip UI Flow
When a farmer marks a task done:
- `PATCH /planner/activities/{id}/complete`
- Optional: add notes ("Used 200L instead of 180L")
- UI animates: checkmark, progress bar increments

When a farmer skips a task:
- `PATCH /planner/activities/{id}/skip`
- Required: reason text ("Too much rain today")
- The skipped reason is stored for AI context
